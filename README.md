# كوت بو ٤ (Flutter + BLoC + Supabase)

لعبة كوت بو ٤ (فريقان × لاعبان، ٣٦ ورقة). تشمل: تصميم بطاولة وأوراق متحركة، مؤثرات صوتية، دخول (ضيف/بريد)، غرف بكود دعوة، لعب أونلاين لـ٤ لاعبين، مؤقت لكل دور، وساعة مدة اللعبة مع إحصائيات.

## التشغيل بدون سيرفر (ضد البوتات فقط)
```bash
flutter create . --platforms=android,ios,web   # مرة واحدة
flutter pub get
flutter run
flutter test
```

## تفعيل الأونلاين (Supabase)
1. أنشئ مشروعاً في supabase.com ثم من **SQL Editor** شغّل محتوى `supabase/schema.sql`.
2. من **Authentication → Providers**: فعّل Email وفعّل **Allow anonymous sign-ins** (وعطّل Confirm email للتجربة).
3. شغّل بالمفاتيح (Project Settings → API):
```bash
# مباشرة من ملف الإعدادات:
flutter run --dart-define-from-file=.vscode/dart_defines.json

# أو بالضغط على F5 من داخل VS Code (تم إعداده في .vscode/launch.json)
```

## كيف يعمل الأونلاين
- **المضيف (صاحب الغرفة) هو الحَكَم**: يشغّل منطق اللعبة والبوتات ويبث لكل لاعب نسخته من الحالة (يده فقط) عبر Realtime Broadcast. باقي اللاعبين يرسلون أفعالهم (مزايدة/حكم/ورقة) للمضيف.
- الغرف والمقاعد في جدول `rooms` وتتحدث لحظياً؛ الدعوة = كود من ٥ أحرف (نسخ أو مشاركة).
- انتهاء مهلة الدور = يلعب عنك البوت حتى ترجع تتصرف.
- نتيجة كل لعبة (فوز/مدة/جولات) تُحفظ في `game_results` وتظهر كعدد ألعاب وانتصارات في الشاشة الرئيسية.

## حدود معروفة (للنسخة الأولى)
- لو خرج المضيف أثناء اللعب تتوقف اللعبة عند الباقين (لا يوجد نقل للمضيفية بعد).
- الحماية من الغش بسيطة: الأيدي لا تُرسل إلا لصاحبها، لكن Broadcast غير مقيّد بصلاحيات لكل لاعب. للمسابقات الجدية انقل منطق الحَكَم إلى Edge Function.
- الدعوة بكود (بدون رابط عميق Deep Link).
- الخط Cairo يُحمَّل من الإنترنت عبر google_fonts؛ يمكنك تضمينه في `assets/` لتشغيل بلا نت.

## الهيكل
- `lib/domain/` منطق نقي (أوراق، قوانين، بوتات) • `lib/bloc/` (`GameBloc`, `AuthCubit`, `LobbyCubit`, `GameCodec`)
- `lib/data/` مستودعات Supabase وجلسة اللعب الأونلاين • `lib/ui/` الشاشات • `lib/core/` الثيم والصوت والإعدادات
- `assets/sounds/` مؤثرات مولّدة بـ `tool/gen_sounds.py` (يمكنك استبدالها بملفات أفضل بنفس الأسماء)
